# Figma Spec — Frame 8: Footer

Frame ID: 1001:2739 (approx)
Size: 1280 × ~300
Type: Footer section

## Description
Footer section with navigation links, social links, and copyright information.

## Verbatim Text Content
- Section headings: varies by column
- Footer links: navigation items, about links, contact links
- Social links: Instagram, Facebook, Twitter
- Copyright: "© 2024 Ace360" or similar
- Contact email: "hello@urbanthreads.com" or similar

## Layout Structure
- Footer container with multiple columns
- Each column: heading + link list
- Bottom: copyright bar
- Right side: social media icons

## Colours
- Footer background: white or light grey
- Footer text: #64748b (secondary)
- Footer links: #1e293b (primary dark)
- Social icons: various brand colours

## Fonts
- Footer headings: Liberation_Sans Bold 14px, uppercase, tracking 0.7px
- Footer links: Liberation_Sans Regular 12px
- Copyright text: Liberation_Sans Regular 12px

## Shadows & Radii
- Footer container: subtle border-top
- Social icons: circle radius

## Assets
- Social media icons (Instagram, Facebook, Twitter)

## Prototype Interactions
- Footer links navigate to respective pages
- Social icons open social profiles in new tab

## Responsive Notes
- Footer columns stack vertically on mobile
- Copyright bar centers on mobile
