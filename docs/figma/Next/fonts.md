# Fonts — Next.js (SOFALIVING Sofa Customiser)

## Font Families

| Family | Source | Weights Used | Usage |
|--------|--------|--------------|-------|
| EB Garamond | Google Fonts | Regular, Medium, Bold | Headings, prices, metric numbers |
| DM Sans | Google Fonts | Regular, Medium, SemiBold, Bold | UI text, body, buttons, labels |

## Typography Styles

### Headings
- **Heading 1** — EB Garamond Bold, 64px, line-height 72px, letter-spacing -1.6px
  - Usage: Hero heading "Bespoke Sofas, Sculpted for Modern Indian Homes."
- **Step Heading** — EB Garamond Medium, 24px, line-height 32px
  - Usage: Customiser step headings ("Choose Sofa Model", etc.)
- **Card Name** — EB Garamond Medium, 24px, line-height 32px
  - Usage: Sofa model names ("The Luna Curved", etc.)
- **Pillar Title** — EB Garamond Medium, 24px, line-height 32px
  - Usage: Manufacturer pillar headings ("Kiln-Dried Hardwood", etc.)
- **Metric Number** — EB Garamond Regular, 64px, line-height 72px, letter-spacing -1.28px
  - Usage: Stats ("26", "42k+", "10-Yr")

## Google Fonts Notes
- Both EB Garamond and DM Sans are available as Google Fonts
- Import via `@import url('https://fonts.googleapis.com/css2?family=EB+Garamond:wght@400;500;700&family=DM+Sans:wght@400;500;600;700&display=swap')`
- Font fallbacks: serif for EB Garamond, sans-serif for DM Sans
